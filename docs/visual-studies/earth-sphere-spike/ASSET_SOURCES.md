# Rejected Earth sphere spike assets

These maps were tested in an isolated Earth sphere spike on 30 August 2026. The
result looked more like a conventional CG globe than the owner-approved cinematic
plate, so the sphere path was rejected before production integration. The files are
kept here for provenance and are not copied into the Vite public bundle.

## Earth technical-prototype maps

Downloaded on 30 August 2026 from the official Three.js examples texture directory:

- `earth-atmos-2048.jpg`
  - <https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg>
- `earth-lights-2048.png`
  - <https://threejs.org/examples/textures/planets/earth_lights_2048.png>
- `earth-clouds-1024.png`
  - <https://threejs.org/examples/textures/planets/earth_clouds_1024.png>

The Three.js repository is MIT licensed, but these example maps remain
**prototype-only because their individual upstream provenance was not confirmed**.
